# 밑바닥부터 시작하는 딥러닝 2 CH.03

1.  **실험 목적**
* **추론 기반 기법 이해**: 주변 단어(맥락)를 통해 빈칸의 단어(타깃)를 예측하는 과정에서 단어의 의미를 학습하는 원리를 이해합니다.
* **word2vec 모델 구현**: CBOW와 Skip-gram 모델의 구조적 차이를 코드로 구현하고, 실제로 단어가 벡터로 변환되는 과정을 확인합니다.

2. **주요 코드별 역할 및 알고리즘**
   
    *   **① CBOW 추론 및 모델 구성 (`cbow_predict.py`, `simple_cbow.py`)**
    *   원리: 맥락 단어들을 입력받아 타깃 단어를 추측합니다.
    *   계층 구조:
        *   입력층: 여러 맥락 단어(원-핫 벡터)가 `MatMul` 계층을 통과합니다.
        *   은닉층: 입력층의 출력값들을 평균(0.5 곱)하여 하나의 벡터로 만듭니다.
        *   출력층: 최종 스코어를 계산하고 `SoftmaxWithLoss`를 통해 손실을 구합니다.

    *   **② Skip-gram 모델 구성 (`simple_skip_gram.py`)**
    *   원리: 하나의 타깃 단어로부터 주변의 여러 맥락 단어를 역으로 추측합니다.
    *   특징: CBOW와 반대되는 구조이며 출력층에서 각 맥락에 대한 손실을 각각 계산하여 합산($l1+l2$)합니다.

    *   **③ 전체 학습 프로세스 (`train.py`)**
    *   데이터 전처리: 텍스트를 ID 목록으로 바꾸고 학습에 필요한 맥락(contexts)과 타깃(target)을 추출한 뒤 원-핫 벡터로 변환합니다.
    *   최적화: Adam 옵티마이저를 사용해 손실을 최소화하는 방향으로 가중치를 갱신합니다.
    *   결과 추출: 학습이 완료된 후 `model.word_vecs`에 저장된 가중치가 바로 각 단어의 분산 표현(벡터)이 됩니다.


3. **실험 조건 및 결과 요약**

| 항목 | 설정값 | 비고 |
| :--- | :--- | :--- |
| **대상 문장** | 'You say goodbye and I say hello.' | 소규모 샘플 데이터 |
| **하이퍼파라미터** | window_size=1, hidden_size=5 | 맥락 범위 및 벡터 차원 |
| **학습 반복** | max_epoch=1000, batch_size=3 | 안정적인 수렴을 위한 설정  |
| **최종 출력** | 각 단어별 5차원 밀집 벡터 | `word_vecs[word_id]` 값 출력  |

* **학습 성과**: `trainer.plot()` 결과, 에폭이 반복됨에 따라 손실(Loss)이 점진적으로 감소하며 단어의 의미가 벡터 공간에 성공적으로 투영되었습니다.
* **분산 표현**: 학습 결과로 각 단어는 무작위 값이 아닌, 문맥적 의미를 내포한 고유의 수치 리스트(벡터)를 갖게 되었습니다.


4. **결론 및 시사점**
* **가중치의 의미**: word2vec 학습이 완료된 후 입력층의 가중치 $W_{in}$의 각 행은 해당 단어의 의미를 응축한 벡터가 됩니다.
* **효율성**: 통계 기반 기법(2장)과 달리, 신경망을 이용한 추론 기반 기법은 미니배치 학습이 가능하여 대규모 데이터셋에서도 가중치를 효율적으로 갱신할 수 있다는 장점이 있습니다.
