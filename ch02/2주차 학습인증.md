# 밑바닥부터 시작하는 딥러닝 2 CH.02

1. **실험 목적**
    *   단어의 분산 표현: 분포 가설에 근거하여 말뭉치(Corpus)로부터 단어를 고정 길이의 벡터로 변환하는 과정을 이해합니다.
    *   통계 기반 기법의 이해: 동시발생 행렬, PPMI, SVD 등의 과정을 거치며 단순 빈도 수가 아닌 단어 간의 실질적인 의미적 유사도를 추출하는 법을 학습합니다.

2. **주요 실험 단계 및 코드 역할**

    *   **① 데이터 전처리 및 말뭉치 확인 (show_ptb.py)**
        *   역할: 텍스트 데이터를 단어 ID 목록 (corpus) 과 딕셔너리 (word_to_id, id_to_word) 로 변환합니다.
        *   PTB 말뭉치: 약 93만 단어로 구성된 거대 말뭉치를 로드하여 실무적인 규모의 데이터를 다룹니다.

    *   **② 동시발생 행렬 및 유사도 측정 (similarity.py, most_similar.py)**
        *   동시발생 행렬 (Co - occurrence Matrix): 주변에 등장하는 단어의 빈도를 벡터화합니다.
        *   코사인 유사도 (Cosine Similarity): 두 단어 벡터가 가리키는 방향이 얼마나 비슷한지를 측정하여 유사도를 구합니다.

    *   **③ 가중치 정교화 (ppmi.py)**
        *   PPMI(Positive Pointwise Mutual Information): 'the' 처럼 빈도만 높은 단어의 영향을 줄이고, 관련성 높은 단어 간의 결합력을 수치화합니다.
        *   결과: 단순 빈도 (C) 보다 PPMI 행렬 (W) 이 단어의 의미를 더 정확하게 반영합니다.

    *   **④ 차원 감소와 시각화 (count_method_small.py, count_method_big.py)**
        *   SVD(Singular Value Decomposition): 거대한 희소 행렬을 핵심 정보만 담긴 밀집 벡터로 압축합니다.
        *   결과: 2차원 평면에 단어들을 플롯했을 때, 'goodbye' 와 'hello' 처럼 의미가 가까운 단어들이 물리적으로도 가깝게 모이는 것을 확인했습니다.

3. **실험 결과 분석**

    | 구분                      | 소규모 말뭉치 (7 단어) | PTB 대규모 말뭉치 (1 만 단어) |
    | ------------------------- | ---------------------- | ----------------------------- |
    | 특징                      | 의미 관계 파악이 시각적으로 명확함 | 실제 사용되는 언어적 유사도 도출 가능 |
    | 유사도 결과                 | 'you' 와 'i' 가 높은 유사도를 보임 | 'car' 검색 시 'luxury', 'auto' 등 유의어 도출 |
    | SVD 방식                  | 기본 np.linalg.svd 사용 가능 | 속도를 위해 randomized_svd 권장 |

    *   **① 말뭉치 규모 및 단어 ID 수치 (PTB 데이터셋)**
        *   ch02/show_ptb.py 실행 결과
        *   대규모 말뭉치의 기초 통계는 다음과 같습니다.
            *   전체 말뭉치 크기: 929,589 개의 단어로 구성되어 있습니다.
            *   주요 단어 ID 매핑:
                *   car : 3856
                *   happy : 4428
                *   lexus : 7426

    *   **② 말뭉치 규모에 따른 'you' 유사도 수치 비교**
        *   동일한 단어 'you' 에 대해 말뭉치의 크기와 처리 기법 (SVD 유무) 에 따라 유사도 수치가 어떻게 달라지는지 비교할 수 있습니다.
            *   소규모 말뭉치 (7 단어): "you" 와 "i" 의 코사인 유사도는 0.7071 로 나타났습니다. (단순 동시발생 행렬 기반)
            *   대규모 말뭉치 (PTB + SVD): "you" 와 가장 유사한 단어로 "i" 가 추출되었으며, 이 때의 유사도는 0.6601 입니다.
                *   분석: 단순 빈도 기반 (0.707) 보다 SVD 를 통한 차원 감소 후의 수치 (0.660) 가 "we"(0.598), "me"(0.553) 등 더 다양한 인칭 대명사와의 관계를 정교하게 포착하고 있습니다.

    *   **③ 동시발생 행렬 vs PPMI 수치 변화**
        *   ch02/ppmi.py 결과를 통해 단순 빈도가 의미론적 가중치로 변환되는 과정을 수치로 확인할 수 있습니다.
            *   단순 빈도 (C): 특정 단어 쌍의 동시발생 횟수가 1 인 경우.
            *   PPMI (W): 동일한 관계가 1.807 이라는 가중치로 변환되었습니다.
            *   의미: 단순 빈도가 1 인 관계들 사이에서도 PPMI 를 통해 1.807, 0.807, 2.807 등 단어 간의 결합 강도에 따라 차별화된 수치가 부여됨으로써 단어의 의미를 더 정확하게 반영하게 됩니다.

    *   **④ PTB 기반 카테고리별 유사도 결과 (SVD 적용)**
        *   ch02/count_method_big.py 에서 SVD 를 통해 추출된 밀집 벡터의 유사도 상위 수치들입니다.
            *   시간 / 시기 관련 : year
                *   quarter : 0.6148
                *   next : 0.6121
                *   month : 0.6037
            *   산업 / 자동차 관련 : toyota (매우 높은 관련성을 보임)
                *   motor : 0.7390
                *   nissan : 0.6791
                *   honda : 0.6520
                *   lexus : 0.5935

4. **최종 결론**

    *   통계 기반 기법의 유효성: 별도의 사전 (시소러스) 없이도 말뭉치의 통계만으로 단어의 의미를 벡터로 훌륭하게 표현할 수 있음을 확인했습니다.
    *   밀집 벡터의 중요성: SVD 를 통한 차원 감소는 데이터 크기를 줄일 뿐만 아니라 단어 간의 핵심적인 의미 관계를 포착하여 더 강력한 분산 표현을 생성합니다.
