# A.ing 2025 겨울방학 DL스터디: 밑바닥부터 시작하는 딥러닝 2

이 저장소는 『밑바닥부터 시작하는 딥러닝 2』를 기반으로 자연어 처리와 시계열 데이터 처리를 위한 딥러닝 기술을 학습하고 구현한 기록입니다. 

## 스터디 개요
* **교재**: 밑바닥부터 시작하는 딥러닝 2 (한빛미디어) 
* **목표**: 외부 라이브러리 의존도를 낮추고 딥러닝 모델의 내부 원리를 직접 구현하며 이해합니다. 
* **학습 기간**: 총 8주 과정

## 주차별 학습 내용
스터디는 총 8개의 챕터로 구성되어 있으며 각 폴더에서 해당 장의 소스 코드를 확인할 수 있습니다. 

| 주차 | 폴더 이름 | 학습 내용 및 설명 |
|:--- |:--- |:--- |
| **1주차** | `ch01` | **신경망의 복습**: 2층 신경망을 통한 비선형 소용돌이 데이터 분류  |
| **2주차** | `ch02` | **자연어와 단어의 분산 표현**: 통계 기반 기법 및 시소러스 활용  |
| **3주차** | `ch03` | **word2vec**: CBOW 모델의 기본 원리와 구현  |
| **4주차** | `ch04` | **word2vec 속도 개선**: Negative Sampling을 이용한 최적화  |
| **5주차** | `ch05` | **순환 신경망(RNN)**: 시계열 데이터 처리의 기초  |
| **6주차** | `ch06` | **게이트가 추가된 RNN**: LSTM과 GRU를 활용한 장기 의존성 해결  |
| **7주차** | `ch07` | **RNN을 사용한 문장 생성**: Seq2seq의 이해와 덧셈 문제 적용  |
| **8주차** | `ch08` | **어텐션(Attention)**: 더 정교한 Seq2seq 모델 구현 및 시각화  |

## 요구사항
소스 코드를 실행하려면 아래의 라이브러리가 설치되어 있어야 합니다. 

* **파이썬 3.x** 
* **NumPy** 
* **Matplotlib** 
* **SciPy / CuPy** (선택 사항) 

## 실행 방법
각 장의 디렉터리로 이동한 후 python 명령을 실행하세요. **(경로 문제로 인해 반드시 해당 디렉터리 내에서 실행해야 합니다.)** 

```bash
# 예시: 1장 실험 코드 실행
$cd ch01$ python train.py
```
