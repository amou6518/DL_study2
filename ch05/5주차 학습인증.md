# 밑바닥부터 시작하는 딥러닝 2 CH.05

1.  **실험 목적**
* **순환 신경망(RNN)의 원리 이해**: 데이터가 순환하는 경로를 통해 과거의 정보를 '은닉 상태'로 저장하고 시계열 데이터를 처리하는 메커니즘을 이해합니다.
* **RNNLM(RNN Language Model) 구현**: 단어 시퀀스를 확률로 해석하여 다음에 올 단어를 예측하는 조건부 언어 모델을 구축합니다.
* **BPTT의 효율적 적용**: 긴 시계열 데이터를 블록 단위로 나누어 학습하는 **Truncated BPTT** 기법의 효과를 실습을 통해 확인합니다.

2. **주요 코드별 역할 및 알고리즘**

* **① SimpleRnnlm 모델 구성 (`simple_rnnlm.py`)**
    * **구조**: `TimeEmbedding` -> `TimeRNN` -> `TimeAffine` 계층으로 구성됩니다.
    * **상태 관리**: `TimeRNN`에서 `stateful=True` 옵션을 사용하여 블록 간 은닉 상태가 끊기지 않고 유지되도록 설계되었습니다.
    * **가중치 초기화**: Xavier 초기값 등을 활용하여 RNN 계층의 학습 안정성을 높였습니다.

* **② 커스텀 학습 루프 및 Truncated BPTT (`train_custom_loop.py`)**
    * **데이터 분할**: 데이터를 블록 단위로 나누되 순전파의 연결은 유지하고 **역전파의 연결만 끊는** Truncated BPTT를 구현하였습니다.
    * **순차적 입력**: 이전 블록의 마지막 상태를 다음 학습의 초기 상태로 사용하기 위해 데이터를 순차적으로 입력하는 로직이 핵심입니다.

* **③ 학습 자동화 및 시각화 (`train.py`)**
    * `RnnlmTrainer`를 사용하여 복잡한 시계열 학습 과정을 효율적으로 관리하고 학습 경과에 따른 **퍼플렉서티(Perplexity)** 변화를 시각화합니다.



3. **실험 조건 및 결과 요약**

| 항목 | 설정값 | 비고 |
| :--- | :--- | :--- |
| **대상 데이터** | PTB 말뭉치 (상위 1,000단어) | 학습 효율을 위한 부분 데이터셋 사용 |
| **하이퍼파라미터** | hidden_size=100, wordvec_size=100 | 모델의 표현 용량 설정 |
| **BPTT 크기** | `time_size = 5` | 역전파가 펼쳐지는 시간 블록 크기 |
| **학습 반복** | `max_epoch = 100` | 손실 수렴을 위한 반복 횟수 |

* **학습 성과**: 에폭이 반복됨에 따라 **퍼플렉서티(Perplexity)** 수치가 안정적으로 감소하는 양상을 보입니다.
* **성능 지표**: 퍼플렉서티는 '다음에 올 단어의 후보 수'로 해석되며, 학습이 진행될수록 모델이 단어의 맥락을 정확하게 좁혀나가고 있음을 나타냅니다.

4. **결론 및 시사점**

* **맥락 기억의 중요성**: RNN은 내부 상태를 통해 이론적으로 모든 과거 정보를 기억할 수 있어 문맥 파악에 강력한 성능을 보입니다.
* **BPTT의 한계 극복**: Truncated BPTT를 통해 매우 긴 시계열 데이터도 메모리 제약 없이 학습할 수 있는 실무적 기법을 익혔습니다.
* **발전 방향**: 현재의 Simple RNN은 긴 시퀀스에서 발생하는 **기울기 소실/폭발 문제**에 취약하므로, 향후 LSTM이나 GRU와 같은 게이트형 RNN으로의 개선이 필요합니다.
