# 밑바닥부터 시작하는 딥러닝 2 CH.01

1.  **실험의 목적**

    *   비선형 문제 해결: 선형 분리가 불가능한 3개의 클래스 (소용돌이 모양) 데이터를 2층 신경망이 정확하게 분류할 수 있는지 확인합니다.

2.  **주요 실험 조건**

    *   데이터: 3개의 클래스, 총 300개의 샘플 (각 클래스당 100개).
    *   모델 구조: 입력층 (2개) → 은닉층 (10개, Sigmoid 활성화) → 출력층 (3개, Softmax).
    *   최적화 도구: 확률적 경사하강법 (SGD), 학습률 (Learning Rate) 1.0.
    *   반복 횟수: 300 에폭 (Epoch).

3.  **실험 결과 요약**

    *   손실값 (Loss)의 변화:
        *   학습 초기에는 약 1.1 수준의 높은 손실을 보이지만, 학습이 진행됨에 따라 꾸준히 감소하여 최종적으로 0.1 내외까지 떨어집니다.
        *   이는 신경망이 데이터의 패턴을 성공적으로 학습하고 있음을 수치적으로 증명합니다.
    *   결정 경계 (Decision Boundary) 형성:
        *   학습 전에는 경계가 없거나 무작위적이지만, 학습 후에는 세 개의 소용돌이 팔을 따라 곡선 형태의 경계선이 명확하게 그어집니다.
        *   복잡하게 꼬인 데이터를 각각의 영역으로 정확히 나누는 모습을 확인할 수 있습니다.

4.  **핵심 결론**

    *   비선형성의 힘: 단순한 선형 변환 (Affine 계층)에 비선형 활성화 함수 (Sigmoid)를 결합함으로써, 신경망은 복잡한 곡선 형태의 표현 능력을 갖추게 됩니다.
    *   계층 구조의 효과: 은닉층의 뉴런들이 데이터를 고차원으로 변환하여, 복잡한 데이터도 분류 가능한 상태로 만들 수 있음을 실증합니다.

> 2층 신경망은 비선형 활성화 함수를 통해 복잡한 소용돌이 데이터를 완벽하게 구분하는 곡선 경계를 스스로 학습해낸다.
