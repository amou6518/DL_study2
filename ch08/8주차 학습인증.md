# 밑바닥부터 시작하는 딥러닝 2 CH.08
본 프로젝트는 고정 길이 벡터의 한계를 극복하고 시계열 데이터 간의 대응 관계를 직접 학습하는 어텐션(Attention) 메커니즘의 구현과 실험 과정을 담고 있습니다.

1.  **실험 목적**
* **병목 현상(Bottleneck) 해결**: Encoder의 모든 정보를 하나의 은닉 상태 벡터에 압축하던 기존 seq2seq의 한계를 어텐션으로 극복합니다.
* **동적 문맥 파악**: Decoder가 출력 단어를 생성할 때마다 입력 문장의 어떤 부분에 집중해야 하는지 스스로 학습하게 합니다.
* **해석 가능한 AI 구현**: 어텐션 가중치를 시각화하여 모델이 특정 결과를 도출할 때 참조한 입력 데이터를 확인합니다.

2. **주요 구현 내용**

① 어텐션 계층 (`attention_layer.py`)
* **AttentionWeight**: Encoder의 은닉 상태들과 Decoder의 은닉 상태 사이의 유사도를 내적(Dot Product)으로 계산합니다.
* **WeightSum**: 계산된 가중치를 이용하여 입력 벡터들의 가중합을 구해 맥락 벡터(Context Vector)를 생성합니다.

② Attention seq2seq (`attention_seq2seq.py`)
* **Encoder**: 모든 시점의 은닉 상태($hs$)를 출력하여 정보를 보존합니다.
* **Decoder**: LSTM과 Affine 계층 사이에 어텐션 계층을 삽입하여 전달받은 $hs$를 효과적으로 활용합니다.

3. **실험 결과 및 분석**

① 학습 성능 (`trian.py`)

| 항목 | 결과값 | 비고 |
| :--- | :--- | :--- |
| **대상 태스크** | 날짜 형식 변환 | "August 14, 2021" → "2021-08-14" |
| **최종 정확도** | **99.96%** | 어텐션 적용 후 완벽한 변환 능력 확보 |

② 어텐션 가중치 시각화 (`visualize_attention.py`)
* 학습된 모델이 단어를 생성할 때 주목하는 위치를 히트맵으로 분석했습니다.
* 분석: "August"라는 출력을 만들 때 입력문의 "August" 영역에 가중치가 집중되는 현상을 확인했습니다.
* 의의: 모델이 단순 암기가 아닌 단어 간의 대응 관계(Alignment)를 이해하고 있음을 입증했습니다.

4. **결론 및 시사점**
* **기술적 도약**: 어텐션 기법은 시계열 데이터의 길이가 길어져도 성능이 저하되지 않는 강력한 해결책임을 확인했습니다.
* **트랜스포머의 토대**: 본 실습을 통해 현대 자연어 처리의 표준인 Transformer 모델의 핵심 원리를 파악하였습니다.
