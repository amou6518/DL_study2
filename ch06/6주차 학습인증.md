# 밑바닥부터 시작하는 딥러닝 2 CH.06

본 보고서는 GPU 가속을 활용하여 고성능 언어 모델인 **Better RNNLM**을 구축하고 LSTM의 효과와 정규화 기법을 실증한 실험 기록을 담고 있습니다.

1.  **실험 목적**
* **장기 의존성 문제 해결**: 기본 RNN의 기울기 소실 문제를 극복하기 위해 **LSTM** 계층을 구현하고 효과를 확인합니다.
* **학습 최적화 및 가속화**: **기울기 클리핑**으로 학습 안정성을 확보하고 **CuPy**를 이용해 GPU 연산 가속을 실현합니다.
* **모델 고도화**: 다층 LSTM, 드롭아웃, 가중치 공유(Weight Tying) 기법을 통합하여 퍼플렉서티(Perplexity)를 개선합니다.

2. **개발 및 실험 환경**
* **GPU**: NVIDIA GeForce RTX 4070 (Laptop/Desktop)
* **Library**: Python 3.11, CuPy (for CUDA 12.x/13.x)
* **Dataset**: PTB (Penn Treebank) Corpus
* **Key Config**: `config.GPU = True` 적용

3. **주요 구현 및 개선 사항**
* **LSTM (Long Short-Term Memory)**: 3개의 게이트(Forget, Input, Output)를 통해 정보의 흐름을 조절하여 장기 기억을 가능케 함.
* **BetterRnnlm 구조**:
    * **다층화**: LSTM 계층을 2층으로 쌓아 복잡한 문맥 파악.
    * **드롭아웃**: 변형된 드롭아웃을 적용하여 과적합 억제.
    * **가중치 공유**: Embedding과 Affine 계층의 가중치를 공유하여 파라미터 수 절감 및 성능 향상.

4. **실험 결과 및 분석**

| 항목 | 설정값 | 비고 |
| :--- | :--- | :--- |
| **에폭 (Epoch)** | 4 | GPU 기반 고속 학습 진행 |
| **은닉층 크기** | 650 | 고차원 밀집 벡터 표현 |
| **초기 퍼플렉서티** | 약 9999.51 | 학습 시작 시점 |
| **최종 퍼플렉서티** | 126.07 | Epoch 4 완료 시점 |

* **GPU 가속 효과**: CPU 환경에서 반복당 1초 이상 소요되던 연산이 GPU 적용 후 획기적으로 단축되어 실용적인 시간 내에 학습 완료.
* **학습 경향**: 초기 높은 수치였던 Perplexity가 에폭이 반복됨에 따라 급격히 하향 안정화되며 모델이 문맥을 학습함을 입증.

5. **트러블슈팅 (Troubleshooting)**
실습 중 발생한 환경 이슈와 해결 과정을 기록합니다.

* **CUDA DLL 로드 에러 (`curand`)**:
   * **원인**: 시스템의 CUDA v13.1과 설치된 CuPy(cuda12x) 간의 경로 인식 문제.
   * **해결**: 시스템 환경 변수 `Path`에 CUDA `bin` 경로를 등록하여 DLL 로드 성공.
* **CuPy API 호환성 이슈 (`scatter_add`)**:
   * **원인**: 최신 CuPy 버전과 교재 제공 코드(`common/np.py`) 간의 속성 명칭 불일치.
   * **해결**: 해당 구문을 주석 처리하여 최신 API 표준에 맞게 수정 후 정상 작동 확인.

6. **결론 및 시사점**
이번 실험을 통해 하드웨어 가속(GPU)이 딥러닝 연구에 미치는 절대적인 영향을 체감하였으며
LSTM과 정규화 기법의 결합이 언어 모델의 성능을 얼마나 비약적으로 향상시키는지 확인하였습니다.
본 모델은 차후 **문장 생성** 및 **Seq2Seq** 모델의 핵심 엔진으로 활용될 예정입니다.
