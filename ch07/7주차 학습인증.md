# 밑바닥부터 시작하는 딥러닝 2 CH.07

1.  **실험 목적**
* **생성 모델로의 확장**: 학습된 언어 모델(RNNLM)이 다음 단어를 확률적으로 샘플링하여 스스로 문장을 생성할 수 있음을 확인합니다.
* **seq2seq 구조 이해**: Encoder-Decoder 구조를 통해 시계열 데이터를 다른 시계열로 변환(번역, 응답 등)하는 원리를 학습합니다.
* **성능 향상 기법 검증**: 입력 데이터 반전(Reverse) 및 정보 공유(Peeky) 기법이 seq2seq의 학습 속도와 정확도에 미치는 영향을 실습합니다.

2. **주요 구현 내용**

① 문장 생성 알고리즘 (`rnnlm_gen.py`)
* **확률적 샘플링**: 가장 확률이 높은 단어만 선택(Deterministic)하지 않고, `np.random.choice`를 사용해 확률 분포에 따라 단어를 선택함으로써 다양성 확보.
* **문맥 유지**: 첫 단어(예: 'you')를 입력한 후 모델이 출력한 단어를 다시 다음 입력으로 사용하는 피드백 루프 구현.

② seq2seq 모델 (`seq2seq.py`, `peeky_seq2seq.py`)
* **Encoder**: 입력 문장을 고정 길이의 은닉 상태 벡터 $h$로 압축.
* **Decoder**: 은닉 상태 $h$를 넘겨받아 '더하기 결과' 문자열을 생성.
* **Peeky 기법**: Encoder의 $h$를 Decoder의 모든 시점(Time Step)에 입력으로 제공하여 정보 소실 방지.

3. **실험 결과 및 분석**
① 문장 생성 결과 비교
* **기본 모델(`generate_text.py`)**: "you like to the leipzig on property."와 같이 단어 간의 연결은 가능하나, 문맥적 의미가 파편화되어 나타납니다.
* **Better 모델(`generate_better_text.py`)**: "the meaning of life is las german credit..." 등 6장의 정규화 기법 덕분에 상대적으로 더 긴 문맥을 유지하며 구조적으로 완성된 문장을 생성합니다.

② 더하기 연산 학습 (`train_seq2seq.py`)
| 모델 설정 | 최종 정확도 | 특징 |
| :--- | :--- | :--- |
| **기본 seq2seq** | 낮음 (약 9.94%) | 25 에폭 내에 연산 규칙을 거의 습득하지 못함(실패) |
| **Reverse + Peeky** | **높음 (약 98.68%)** | 7 에폭 부근에서 정확도가 급상승하며 완벽에 가까운 연산 능력 확보 |

* **정확도 급상승 지점**: Reverse와 Peeky를 동시에 적용했을 때 학습 초기(5~8 에폭)에 정확도가 수직 상승하는 구간이 발견되었습니다.
* **연산 실례**: "Q 975+164"에 대해 "T 1139, O 1139"를 출력하며 3자리 수 덧셈도 정확히 수행함을 확인했습니다.

4. **트러블슈팅 (Troubleshooting)**
* **데이터 반전(Reverse)의 마법**: 단순히 입력 순서를 뒤집는 것만으로도 Encoder와 Decoder 사이의 관련 정보 거리가 가까워져 기울기 전파가 원활해짐을 확인.
* **언어 모델의 가능성**: 언어 모델이 단순히 단어를 맞히는 것을 넘어 '더하기'와 같은 논리적인 시퀀스 규칙도 학습할 수 있음을 실증함.

5. **결론 및 시사점**
* Encoder가 생성한 벡터 $h$가 Decoder의 모든 계층에 전달되는 Peeky 기법이 단순 seq2seq 대비 정확도를 약 10배 이상(9% → 98%)끌어올리는 핵심 동인임을 확인했습니다.
* RNN이 단순 텍스트 생성을 넘어 '덧셈'이라는 논리적 연산 규칙까지 스스로 학습할 수 있다는 점을 통해 인공지능이 데이터로부터 추상적인 규칙을 추출하는 능력을 실증하였습니다.
